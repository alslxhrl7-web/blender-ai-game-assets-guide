1\. 개요

이 문서는 보는 사람이 직접 조작하지 않는 관람형 시연(B안)용이다. 연습한 시연자가 플레이하고 기획자가 옆에서 해설한다. 목표는 누가 해도 무너지지 않는 게임이 아니라, 정해진 3분을 가장 좋게 보여주는 빌드다. 그래서 적 AI, 밸런스, 실패 처리에 드는 시간을 줄이고 그만큼 연출, 화면, 소리에 쓴다. 보는 사람이 직접 플레이하는 시연은 「시연 빌드 기획서 A안」을 따른다.

핵심 경험 한 줄: **조명탄이 뜨면 숨고, 꺼지면 움직인다. 그리고 끝에는 점수 대신 한 사람의 이름이 남는다.**

언제 B안을 쓰나

| **상황**                                                | **버전**                     |
|---------------------------------------------------------|------------------------------|
| 여러 명이 큰 화면으로 보는 자리 (발표회, 지원사업 심사) | B안 라이브 시연              |
| 온라인 피칭, 시간이 10분 이하로 짧은 자리               | B안 녹화 영상 또는 화면 공유 |

| 1~3명이 PC 앞에 앉아 직접 해 보는 자리                  | A안 (별도 문서)              |

A안과 무엇이 다른가

| **항목**        | **A안 (직접 플레이)**                   | **B안 (관람)**                                      |
|-----------------|-----------------------------------------|-----------------------------------------------------|
| **적 AI**       | 감지와 엄폐를 스스로 판단하는 상태 머신 | 정해진 경로로 나와 정해진 자리에서 쏘는 스크립트 적 |
| **공세**        | 플레이에 따라 달라진다                  | 매번 같은 순서로 등장한다                           |
| **조명탄**      | 무작위 간격 + 고정 2발                  | 모두 고정 타이밍                                    |
| **T-34**        | 바주카 판정, 실패선, 제한 시간          | 측면 2발에 멈추는 판정만. 실패 없음                 |
| **실패·재시작** | 사망, 체크포인트, 처음부터 다시         | 없음. 시연자용 무적 키로 대신                       |
| **조작 안내**   | 화면 문구                               | 없음. 해설이 대신                                   |
| **연출**        | Timeline 3개                            | Timeline 4개. 트럭 도착 도입과 태석 합류 장면 추가  |
| **사운드**      | 헤드폰 기준                             | 스피커 기준 믹스                                    |
| **화면**        | 성능 우선                               | 큰 화면과 녹화 기준 품질 우선                       |

추천 진행 방식

초보 팀이라면 B안 빌드를 먼저 목표로 잡는 쪽이 안전하다. 플레이어·무기, 조명탄, 연출, 미션 종료 화면은 두 안이 똑같이 쓰기 때문에 버려지는 작업이 없다. 10월 22일 점검 때 여유가 있으면 스크립트 적을 상태 머신 AI로 바꾸고 실패·재시작을 붙여 A안으로 넓힌다. 여유가 없으면 B안으로 시연한다.

2\. 레벨 기획

맵과 구역은 A안과 같다. 같은 맵을 쓰기 때문에 나중에 A안으로 넓힐 때 다시 만들 필요가 없다. B안에서는 실패선과 체크포인트를 쓰지 않는다.

| **구역**           | **역할**                           | **B안에서 쓰이는 비트** |
|--------------------|------------------------------------|-------------------------|
| **A 진지**         | 시연자가 대부분의 시간을 보내는 곳 | 도입 끝부터 새벽까지    |
| **B 전방 경사면**  | 적이 정해진 순서로 올라오는 곳     | 첫 조명탄, 공세         |
| **C 계곡 도로**    | 트럭 하차, T-34 경로, 보충병 등장  | 도입, T-34, 새벽        |

B안에만 있는 지점

| **지점**                   | **위치**                                            | **비트** |
|----------------------------|-----------------------------------------------------|----------|
| **트럭 하차 지점**         | C 도로 남쪽 끝, 진지에서 약 40m                     | 도입     |
| **도입 걷기 경로**         | 하차 지점 → A 진지 오른쪽 입구 → 플레이어 시작 위치 | 도입     |
| **어둠 속 이동 시연 구간** | A 진지 안, 왼쪽 모래주머니 → 가운데                 | 공세     |
| **탄약 상자**              | A 진지 가운데, 플레이어 시작 위치 뒤                | 공세     |
| **태석이 앉는 자리**       | 플레이어 시작 위치 오른쪽 옆                        | 새벽     |
| **보충병 등장 경로**       | C 도로 남쪽 → A 진지 오른쪽 입구                    | 새벽     |

거리 기준은 A안과 같다. 진지에서 적이 처음 보이는 곳까지 50~80m, 도로까지 30~40m다. 큰 화면에서 보는 관객을 위해, 적이 멈춰 쏘는 자리는 조명탄 아래에서 실루엣이 뚜렷하게 보이는 곳으로 고른다.

시연자가 매번 똑같이 따라 하는 조작 순서다. 각 동작이 무엇을 보여주려는 것인지 함께 적었다.

| **시간**  | **위치**        | **시연자가 할 일**                                            | **보여주려는 것**         |
|-----------|-----------------|---------------------------------------------------------------|---------------------------|
| 0:00~0:25 | 트럭 → A 진지   | 마우스로 주변을 천천히 둘러본다. 이동은 자동                  | 1950년의 계곡과 진지      |
| 0:25      | A 시작 위치     | 엎드린다                                                      | 엎드리기 자세             |
| 0:28~0:40 | A               | 조명탄 아래에서 정찰병 2명을 각각 두 발로 쓰러뜨린다          | 밝을 때 쏘는 리듬         |
| 0:40~0:55 | A 가운데        | 진입로 2에서 오는 3명을 쏜다                                  | 공세 시작                 |
| 0:55~1:05 | A 왼쪽 → 가운데 | 조명탄이 꺼진 사이 엄폐물 사이를 옮긴다                       | 어두울 때 움직이는 리듬   |
| 1:05~1:15 | A 가운데        | 탄을 다 쓰고 탄약 상자에서 F로 보충한다                       | M1 클립의 '핑', 부족한 탄 |
| 1:15~1:25 | A               | 진입로 1·3의 남은 4명을 쏜다                                  | 공세 마무리               |
| 1:25~1:45 | A               | 시점을 천천히 왼쪽 참호 구석으로 돌려 담요를 덮은 형체를 본다 | 총을 쏘지 않는 시간       |

| 1:55~2:00 | A               | 바주카로 바꿔 전차 정면에 1발을 쏜다                          | 정면은 통하지 않는다      |
| 2:00~2:10 | A → D           | 둔덕으로 달려간다. 주변에 기관총 사격이 떨어진다              | 달리는 긴장               |
| 2:10~2:25 | D               | 전차 측면에 2발을 쏜다                                        | 측면을 노려야 멈춘다      |
| 2:25~2:50 | 새벽의 A 진지   | 시점만 움직여 옆에 앉는 태석의 뒷모습을 본다                  | 학도병과의 첫 만남        |

시연자는 이 순서를 3분 ±5초 안에서 3회 연속 똑같이 해낼 수 있을 때까지 연습한다. 실수해도 다음 비트가 제시간에 시작되도록, 비트가 끝나면 남은 적은 자동으로 쓰러지거나 물러난다 (4장).

4\. 이벤트·수치 설정

B안에는 플레이마다 달라지는 판단이 없다. 대신 언제, 어디서, 무엇이 일어나는지를 정확히 정한다. 시각과 값은 모두 데이터로 빼서 기획이 인스펙터에서 맞춘다.

스크립트 적 (EnemyData)

| **항목**           | **값**                                                                   | **비고**                    |
|--------------------|--------------------------------------------------------------------------|-----------------------------|
| **행동**           | 스폰 → 정해진 엄폐 지점까지 이동 → 그 자리에서 사격 반복 → 맞으면 쓰러짐 | 감지·판단 없음              |
| **체력**           | M1 몸통 두 발, 머리 한 발                                                | A안과 같은 손맛             |
| **사격**           | 2~3초 간격, 플레이어 근처로 빗나가게                                     | 위협감만 준다               |
| **비트 종료 처리** | 비트가 끝날 때 남은 적은 쓰러지거나 능선 너머로 물러난다                 | 시간 고정을 지키기 위해서다 |

플레이어

시연자 무적이 기본으로 켜져 있다 (F10으로 끈다). 맞으면 화면 가장자리 연출만 나온다. 이동 속도와 엎드리기 효과는 A안과 같다.

- 크로스헤어 점 하나만 남긴다. 남은 탄, 상호작용 문구, 목표 문구는 끈다. 시연자는 동선을 외우고 있고, 설명은 해설이 맡는다.

QA (마감 10/29)

1.  시연자가 동선대로 3분 ±5초 안에 3회 연속 끝낸다.

2.  비트가 시작하는 시각이 흐름표와 ±3초 안에서 맞는다.

3.  시연자가 실수해도 다음 비트가 제시간에 시작된다 (남은 적 자동 처리, T-34 자동 정지).

9\. 시연 운영과 미결정 사항

진행 순서 (약 12분)

4.  질문과 피드백 (5분)

이번 시연: NC 관계자

시연 대상은 NC 관계자다. 바르코3D를 만든 회사이자 게임 회사이므로, 게임의 정서와 함께 '바르코3D로 이만큼 만들었다'는 제작 과정을 보여주는 것이 중요하다. 소수가 PC 앞에 앉는 미팅인지, 큰 화면으로 보는 발표인지는 10/11까지 확인한다.

**바르코3D 활용 자료 (10/29까지 정리)**

- 소품 한두 개의 제작 과정 전후 비교: 생성 이미지 → 바르코3D 메시 → 블렌더 정리 → 게임 화면 속 모습

- 바르코3D로 만든 소품 수와 그중 실제 게임에 쓴 수

- 소품 하나에 든 시간과 크레딧

- 고증 검수에서 바로잡은 사례: AI가 틀린 부분과 고친 방법

- 잘 맞았던 점과 아쉬웠던 점. 만든 회사 앞이라 솔직한 개선 의견이 오히려 가치가 있다

이 자료를 위해 아트 담당은 2주차부터 생성 이미지, 메시, 정리 전후 화면을 그때그때 캡처해 둔다. 시연 직전에 다시 만들려면 시간이 몇 배로 든다.

- 정적, 새벽, 미션 종료 화면에서는 시연자가 시점을 천천히 움직이고, 진행자는 말하지 않는다.

- 라이브 시연에 문제가 생기면 바로 해설 포함 녹화 영상으로 바꾼다.

준비물
