## 같이 작업하는 규칙

1. **시작하기 전에 받는다.** GitHub Desktop에서 `Fetch origin` 뒤 `Pull`.
2. **자기 브랜치에서 한다.** `Current Branch > New Branch`로 `이름/하는일` 형식(예: `minjae/bazooka`)의 브랜치를 만든다. `main`에 바로 올리지 않는다.
3. **씬 파일은 한 번에 한 사람만 고친다.** `M01_Dabudong.unity`는 두 사람이 동시에 고치면 합칠 수 없다. 고치기 전에 단체방에 말하고, 끝나면 바로 올린다.
4. **`.meta` 파일을 같이 올린다.** 파일을 새로 만들면 같은 이름의 `.meta`가 생긴다. 빼먹으면 다른 사람 PC에서 연결이 끊긴다.
5. **올릴 때는 무엇을 바꿨는지 한 줄로 적는다.** 그리고 [WORKLOG.md](WORKLOG.md)에 결과를 성공·부분·실패·미확인으로 남긴다.
6. **끝나면 Pull request를 만든다.** GitHub Desktop의 `Create Pull Request`. 검사 메뉴를 돌려 실패 0건인지 확인하고 합친다.

GitHub Desktop의 변경 목록에 `Library`, `Logs`, `Shots`, `UserSettings`가 보이면 올리지 않는다(원래는 자동으로 빠진다).
