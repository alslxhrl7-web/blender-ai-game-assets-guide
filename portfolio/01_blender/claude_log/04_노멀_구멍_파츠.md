# 요청 4 — 뒤집힌 면 · 구멍 · 파츠 분리

## 요청문 (원문)
> 1) 파츠 분리: 석구의 철모를 별도 오브젝트로 분리해줘(나중에 벗거나 바꿀 수 있게). 진지는 모래주머니 벽을 앞줄·옆줄 단위로 나눠서 유니티에서 배치를 바꿀 수 있게 해줘. 결과를 Outliner가 보이게 캡처해줘.
> 2) 뒤집힌 면: 세 리소스 모두 노멀을 바깥쪽으로 다시 계산하고, Face Orientation 오버레이 전·후를 캡처해줘.
> 3) 구멍: Non-Manifold 가장자리가 있는 오브젝트 이름과 개수를 출력하고, 메울 수 있는 곳은 Fill이나 Grid Fill로 메워줘.

## 실패하고 고친 것
| 문제 | 원인 | 해결 |
|---|---|---|
| 노멀 재계산 뒤 석구 18,349면이 전부 안쪽을 향함 | 철모를 떼어 낸 머리가 열린 메시가 되자 `recalc_face_normals`가 안쪽을 골랐다 | 재계산 뒤 부호 있는 부피를 계산해 음수면 전체를 뒤집는다 |
| 철모에 이마 피부가 딸려 옴 | 높이(챙 1.514 m)로만 잘라서 | 면의 UV 위치에서 베이스 컬러를 읽어 피부색(R > G×1.15)은 빼고, 가장 큰 연결 덩어리만 철모로 |
| 철모를 뗀 머리 구멍이 안 메워짐 | 고리가 단순 루프가 아니라 `holes_fill`이 0면 | `triangle_fill`로 대체 |
| Face Orientation 캡처가 파랗게 안 나옴 | Blender 5.x 테마 기본값에서 앞면 색이 투명 | 캡처할 때만 앞면 파랑·뒷면 빨강으로 테마 지정 |

## 출력
```
파츠: Seokgu_Helmet 1,271 tris(분리 직후), 챙 높이 1.514 m / 반지름 0.162 m
      Sandbag_Wall_Front 6,131 / Wall_Left 3,397 / Wall_Right 3,039 / Ground 27,433 tris (부모 Env_SandbagPosition)

오브젝트            뒤집혔던 면  non-manifold 전 → 후  메운 면
Seokgu                 74         135 → 135          0   (머리 절단부, 철모에 가려짐)
Seokgu_Helmet           0         203 → 80          29
M1Garand                0           0 → 0            0
Sandbag_Ground         27       1,211 → 1,037       23
Sandbag_Wall_Front    477         545 → 522          4
Sandbag_Wall_Left      47         463 → 376          9
Sandbag_Wall_Right     21         415 → 382          4
```

## 확인한 내용
- 원본 Face Orientation은 세 리소스 모두 대부분 파란색이었다. 뒤집힌 면은 진지 앞벽 477면이 가장 많았다.
- 진지의 non-manifold 가장자리는 대부분 지형 바깥 테두리와 벽을 자른 경계다. 바닥에 놓이는 면이라 메우지 않았다. 64변 이하 작은 구멍만 메웠다.
- 석구 머리의 남은 135개는 철모 아래에 가려지는 자리다. 철모를 벗은 상태를 쓰려면 맨머리 모델이 따로 필요하다.
