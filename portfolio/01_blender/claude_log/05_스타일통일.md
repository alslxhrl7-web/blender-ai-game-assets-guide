# 요청 5 — 스타일 통일 (1950년 여름 흙먼지 톤)

## 요청문 (원문)
> 세 리소스를 같은 조명(Material Preview)에서 나란히 놓고 캡처해서 `captures/before/style.png`로 저장해줘.
> 기준은 1950년 여름 낙동강 전선의 흙먼지 낀 사진 느낌이다. 군복·목재·마대는 Hue/Saturation/Value 노드로 Value 0.85~0.9, 채도는 0.9로 낮추고, 금속(철모·총열·리시버)은 Metallic 0.8~1.0, Roughness 0.4~0.55로 맞춰줘. 같은 조명에서 다시 캡처해서 `captures/after/style.png`로 저장해줘.

## 판단: 노드 대신 텍스처에 굽기
FBX는 Hue/Saturation/Value 노드를 싣지 못해 Unity에 가면 효과가 사라진다. 그래서 HSV 노드와 같은 계산(선형 색 공간에서 Saturation ×0.9, Value ×0.87)을 베이스 컬러 텍스처 픽셀에 직접 적용했다. 금속은 ORM 텍스처(R=AO, G=Roughness, B=Metallic)에서 Metallic > 0.5인 픽셀만 Metallic 0.8~1.0, Roughness 0.4~0.55로 다시 매핑했다. 철모는 분리한 뒤 전용 재질(Metallic 0.85, Roughness 0.5)을 줬다. 코드는 `scripts/s4_s6_process.py` `style()`.

## 출력
```
seokgu  hsv 평균색 sRGB (0.434,0.408,0.326) → (0.407,0.385,0.317) / 금속 픽셀 0.09% : (M 0.52, R 0.50) → (0.81, 0.49)
garand  hsv 평균색 sRGB (0.401,0.317,0.256) → (0.376,0.307,0.261) / 금속 픽셀 32.1% : (M 0.64, R 0.39) → (0.86, 0.40)
sandbag hsv 평균색 sRGB (0.448,0.313,0.208) → (0.420,0.308,0.229) / Metallic 맵 없음
텍스처 4K → 2K: 석구 base_color·orm, 진지 base_color
```

## 확인한 내용
- 진지의 채도(선형 평균 0.79)가 가장 높아 붉은 흙이 튀었다. 조정 뒤 세 리소스의 밝기 차가 줄었다(`captures/before/style.png` ↔ `captures/after/style.png`).
- 소총은 금속 비율이 32%로 리시버·총열이 ORM에 금속으로 들어 있었다. 석구의 ORM에는 금속이 거의 없어서(0.09%) 철모 금속값은 분리한 재질로 줬다.
