1. 게임 컨셉

제목《다섯 개의 강: The Forgotten War》
장르1인칭 FPS 싱글 캠페인. 시연 구간은 미션 1 「다부동」 야간 방어 3분
배경1950년 8월 경북 칠곡 다부동, 낙동강 방어선. 조명탄이 뜨면 숨고 꺼지면 움직이는 야간 참호전.
주인공오석구(24). 징집된 지 열흘 된 국군 신병. 철모, 바랜 HBT 작업복, 탄띠·수통, 감은 각반. M1 개런드를 든다.
아트 방향1950년 종군 사진 느낌의 실사. 바랜 카키·흙색·마대색 바탕에, 밤 장면은 조명탄의 흰빛이 유일한 강조색. 약한 필름 그레인과 비네트.
톤 원칙점수 대신 이름이 남는다. 전쟁의 비참함을 보여주되 설교하지 않는다.

리소스 선정 이유

  • 캐릭터 – 주인공 오석구: 사람 형태라 자동 리깅(Humanoid)이 가능하고, 분대원 모델로도 다시 쓸 수 있어 Idle·Walk 애니메이션이 반드시 필요하다. 1950년 국군 복장을 당시 사진과 대조해 고친 고증 과정이 있다.
  • 소품 – M1 개런드: 석구가 들고 싸우는 주무기. 캐릭터와 같은 시대의 목재·파커라이징 강철 재질이라 스타일 통일을 확인하기 좋다. 길고 가는 형태라 AI 생성에서 떠 있는 조각이 많이 생겨 정리 효과가 분명하다.
  • 배경 – 모래주머니 진지: 시연 3분 중 대부분을 보내는 A 진지. 폴리곤이 가장 많아 최적화 전후 차이가 크고, 모래주머니 벽·판자·흙을 나누는 파츠 분리 대상이 있다.
게임 기준 규격 — 1 Blender unit = 1 m, Unity 스케일 1 기준. 석구 키 약 1.70 m, M1 개런드 길이 약 1.10 m, 진지 폭 약 6 m · 깊이 약 5.6 m(모래주머니 벽 높이 약 1.7 m). 원점은 모두 바닥 중앙(석구는 두 발 사이, 소총은 개머리판 바닥 중앙), 정면은 Blender −Y(Unity +Z).

3. Blender 정리 ① 게임 규격 · 최적화

게임 규격 정리 크기 · 원점 · 방향 · Apply Transform

  1. FBX 가져오기 후 N 패널 → Dimensions로 실제 크기 확인. VARCO 출력물은 가장 긴 변이 약 1로 맞춰져 나와서, 기준 크기로 Scale을 조정한다.
  2. 정면이 −Y를 향하도록 Z축 회전, 바닥이 Z=0에 오도록 이동
  3. 원점을 바닥 중앙으로: 3D 커서를 바닥 중앙에 두고 Object → Set Origin → Origin to 3D Cursor
  4. Ctrl+A → All Transforms 적용 → Rotation 0 / Scale 1 확인 (Claude 활용 요청 1 스크립트로 일괄 처리)

4. Blender 정리 ② 스타일 통일 · 게임용 편집/검수

스타일 통일 머티리얼 색 · 질감 맞추기

세 리소스가 각각 다른 이미지에서 생성되어 밝기와 채도가 다르다. 1950년 여름 낙동강 전선의 흙먼지 낀 종군 사진 톤에 맞춘다.

기준조정 방법 (Shader Editor)
군복 · 목재 · 마대 어둡고 바래게Base Color 뒤에 Hue/Saturation/Value 노드, Value 0.85~0.9, Saturation 0.85~0.9
금속 질감 통일철모 · 총열 · 리시버: Metallic 0.8~1.0, Roughness 0.4~0.55 (파커라이징은 반짝이지 않는다)
흙먼지 톤 맞추기진지의 마대·흙 색을 기준으로 석구 군복과 소총 목재의 붉은 기를 Saturation 0.9로 약하게
강조색 쓰지 않기Emission 없음. 밤 장면의 강조는 Unity 조명탄 조명이 맡는다
FBX는 셰이더 노드를 싣지 못하므로 HSV 노드와 같은 계산(선형 공간 Saturation ×0.9, Value ×0.87)을 베이스 컬러 텍스처에 구웠다. 금속은 ORM 텍스처에서 Metallic > 0.5 픽셀만 0.8~1.0 / Roughness 0.4~0.55로 매핑(소총 금속 32%: 평균 M 0.64→0.86), 철모는 분리 후 전용 재질 M 0.85·R 0.5.

① Mixamo 시도 · 대체 이유

정리한 메시를 Mixamo Auto-Rigger에 올렸지만 네 번 모두 "기존 골격을 매핑할 수 없습니다"로 실패했다: 정리 FBX(텍스처 포함) → 한 메시로 합친 FBX(텍스처 제외, 0.7 MB) → OBJ+텍스처 zip → VARCO 원본 FBX. 파일을 열어 보니 뼈대(LimbNode·Skeleton)가 0개였고, 뼈대를 담을 수 없는 OBJ와 VARCO 원본도 같은 오류가 나서 파일이 아닌 서비스 쪽 문제로 판단했다. 같은 워크플로 「다섯개의강」의 VARCO Rig(Humanoid) → Animate 노드로 Idle·Walk를 만들었다.

② VARCO 노드 · Blender 정리

Rig(Humanoid) → Animate 대기1 · 걷기
  1. Animate FBX 2개(각 200,000 tris 원본 메시 + 본 18개, Head 본 없음)를 가져와, 원본 메시 바운딩 박스를 정리 메시(1.70 m)에 맞춰 아마추어를 ×1.7009로 옮긴 뒤 스케일 적용 → Rotation 0 / Scale 1. 위치 키프레임도 같은 배율로 곱함
  2. 정리 메시(20,143 tris)에 Data Transfer로 원본 정점 웨이트를 옮기고 아마추어에 연결. 철모는 Neck 본에 100% 고정
  3. 실패 → 수정: 처음엔 원본 메시가 걷기 첫 자세(보폭 벌린 상태)로 변형된 채 웨이트를 옮겨 다리 면이 길게 찢어졌다 → 옮기는 동안 아마추어를 Rest 자세로 두어 해결(원본과 같은 변형 확인)
  4. 다리 흔들림으로 구분해 액션 이름 Idle(다리 2°) / Walk(다리 크게 흔들림, 루트 이동 2.6 cm = 제자리), Fake User, NLA 트랙 2개
  5. Export: Armature + Mesh, FBX All, −Z / Y, Apply Transform, Bake Animation · NLA Strips → Hero_Seokgu.fbx 14.4 MB

6. Claude 활용 기록 Claude 활용

Blender에서 반복되는 작업을 Claude에게 요청하고, 받은 코드를 Scripting 탭에서 실행했다. 기록마다 요청문 · 결과 · 확인 내용을 남긴다.

요청 1 — 게임 규격 일괄 정리게임 규격
"Blender 4.x에서 선택한 메시마다 회전·스케일을 적용하고, 기준 크기(석구 키 1.70 m, 소총 길이 1.10 m, 진지 폭 6 m)에 맞게 균등 스케일한 다음, 원점을 바운딩 박스 바닥 중앙으로 옮기고 월드 원점에 놓는 스크립트를 만들어줘. 전후 크기를 출력해줘."
import bpy
from mathutils import Vector

# 오브젝트 이름 일부 : (기준 축, 목표 길이 m)  Z=키, X=길이/폭
TARGET = {"Seokgu": ("Z", 1.70), "Garand": ("X", 1.10), "Sandbag": ("X", 6.00)}

for obj in [o for o in bpy.context.selected_objects if o.type == 'MESH']:
    key = next((k for k in TARGET if k.lower() in obj.name.lower()), None)
    bpy.ops.object.select_all(action='DESELECT')
    obj.select_set(True); bpy.context.view_layer.objects.active = obj
    bpy.ops.object.transform_apply(location=False, rotation=True, scale=True)
    before = tuple(round(d, 3) for d in obj.dimensions)
    if key:
        axis, length = TARGET[key]
        cur = getattr(obj.dimensions, axis.lower())
        obj.scale *= length / cur
        bpy.ops.object.transform_apply(location=False, rotation=False, scale=True)
    corners = [obj.matrix_world @ Vector(c) for c in obj.bound_box]
    cx = sum(v.x for v in corners) / 8; cy = sum(v.y for v in corners) / 8
    minz = min(v.z for v in corners)
    bpy.context.scene.cursor.location = (cx, cy, minz)
    bpy.ops.object.origin_set(type='ORIGIN_CURSOR')
    obj.location = (0, 0, 0)
    print(obj.name, before, "→", tuple(round(d, 3) for d in obj.dimensions))

Unity에서 X 270°가 붙어 FBX Apply Transform을 켬 (실행본 scripts/s3_spec.py)
요청 2 — 목표 삼각형 수로 Decimate 최적화최적화
"선택한 오브젝트의 현재 삼각형 수를 세고, 목표 삼각형 수(석구 20000, 소총 5000, 진지 40000)에 맞게 Decimate 비율을 계산해서 모디파이어를 적용하고, 전·후 삼각형 수를 출력해줘."
import bpy
TARGET = 20000   # 소총 5000, 진지 40000으로 바꿔서 실행

obj = bpy.context.active_object
def tris(o):
    o.data.calc_loop_triangles()
    return len(o.data.loop_triangles)

before = tris(obj)
mod = obj.modifiers.new("Decimate_Game", 'DECIMATE')
mod.ratio = min(1.0, TARGET / before)
ratio = mod.ratio
bpy.ops.object.modifier_apply(modifier=mod.name)
print(f"{obj.name}: {before} → {tris(obj)} tris (ratio {ratio:.3f})")

요청 3 — 떠 있는 작은 조각 정리최적화 · 검수
"AI로 만든 모델에 떠 있는 작은 조각이 많아. 활성 오브젝트를 떨어진 조각별로 나눈 뒤, 정점 수가 전체의 1%보다 적은 조각은 삭제하고 나머지는 다시 합쳐줘. 소총의 가늠쇠처럼 작아도 필요한 부품이 지워지지 않았는지 확인할 수 있게 지운 조각의 위치도 출력해줘."
import bpy
obj = bpy.context.active_object
bpy.ops.object.mode_set(mode='EDIT')
bpy.ops.mesh.select_all(action='SELECT')
bpy.ops.mesh.separate(type='LOOSE')
bpy.ops.object.mode_set(mode='OBJECT')

parts = list(bpy.context.selected_objects)
total = sum(len(p.data.vertices) for p in parts)
keep, removed = [], []
for p in parts:
    if len(p.data.vertices) < total * 0.01:
        removed.append((p.name, tuple(round(c, 2) for c in p.matrix_world.translation)))
        bpy.data.objects.remove(p, do_unlink=True)

        keep.append(p)
bpy.ops.object.select_all(action='DESELECT')
for p in keep: p.select_set(True)
bpy.context.view_layer.objects.active = keep[0]
bpy.ops.object.join()
print("removed:", len(removed), "kept:", len(keep))
for r in removed: print("  ", r)

요청 4 — 뒤집힌 면 일괄 수정 · 구멍 찾기편집 · 검수
"선택한 모든 메시의 노멀을 바깥쪽으로 다시 계산하고, 열린 가장자리(Non-Manifold)가 있는 오브젝트 이름과 개수를 알려줘."
import bpy, bmesh
for o in [o for o in bpy.context.selected_objects if o.type == 'MESH']:
